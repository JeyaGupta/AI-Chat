# AI Chat

A simple AI chatbot built using Python that interacts with users and provides responses to their questions.

## Features

* Simple chat interface through the terminal
* User can enter questions or messages
* Provides AI-generated responses
* Easy to run and understand

## Technologies Used

* Python
* AI / Chatbot concepts

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code or Terminal.
3. Run the following command:

```bash
python aichat.py
```

## Project File

* `aichat.py` — Main Python file containing the chatbot code.

## Purpose

This project was created as a beginner-friendly Python AI project to learn about chatbot development and AI concepts.
